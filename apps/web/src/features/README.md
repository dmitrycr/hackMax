# Области интерфейса

Здесь появятся `packages` (комплекты и файлы), `checks` (прогресс и замечания),
`requirements` (кабинет методиста) и `identity` (сессия MAX).

Общий HTTP-клиент находится в `shared/api`. Токен бота и сервисный токен Python
никогда не передаются в браузер. Сейчас реализован только экран состояния инфраструктуры.
