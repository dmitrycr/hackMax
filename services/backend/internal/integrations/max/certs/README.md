# Russian Trusted Root CA

Публичный корневой сертификат Минцифры для проверки TLS API MAX.
Закрытых ключей в каталоге нет.

- Страница распространения: https://www.gosuslugi.ru/crt
- Источник файла: https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer
- Получен по HTTPS с проверкой сертификата сервера 22 сентября 2026 года.
- Subject / Issuer: `C=RU, O=The Ministry of Digital Development and Communications, CN=Russian Trusted Root CA`.
- Срок: `2022-03-01 21:04:15 UTC` — `2032-02-27 21:04:15 UTC`.
- SHA-256 отпечаток сертификата (DER):
  `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`.

Отпечаток рассчитан после скачивания; это запись происхождения и контроль
последующих изменений, а не независимое подтверждение источника.
Исходный `.cer` нормализован в PEM через `openssl x509`.

Файл встраивается через `go:embed` в клиент MAX и добавляется к системным
доверенным сертификатам только в его `tls.Config.RootCAs`. Docker получает его
в составе Go-бинарника, отдельная установка в ОС или монтирование не нужны.
Сертификаты конечных серверов и промежуточные сертификаты не добавляются как
корневые доверенные: цепочку до этого корня должен передавать сервер.

Для обновления скачайте новый сертификат с официального источника по проверенному
HTTPS, проверьте назначение CA, срок и отпечаток, обновите файл, эту запись и тест
отпечатка. Пересоберите и перезапустите бот. Не скачивайте доверенный корень с `-k`.
